# soft-fms

Build YM-FMS — Yellow Machine Fleet Management System — exactly as specified: a dark, professional React/TypeScript/Tailwind/Supabase role-based fleet management platform for SPPCC Liberia. Implement Supabase auth/database with roles and secure scoped access, seed 19 hubs and 285 machines plus the described demo data, and deliver distinct HQ Admin, Hub Supervisor, Field Operator (mobile-first), and Ministry Analyst experiences. Include all requested pages/modules, real-time updates, alerts/notifications, deep-linked router URLs, filters, tables/forms, loading/empty/offline states, and the stated GitHub/Linear-inspired design system. Enable Lovable Cloud/Supabase as needed, build a complete cohesive app, and use the provided demo credentials/password convention.
