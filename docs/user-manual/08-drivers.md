# Driver Registry

## Overview

The official record of every driver: personal details, licence, machine certifications and employment. Staff numbers are generated automatically and cannot be edited.

## What you see

**Driver table.** Columns: Staff No, Name, Phone, Licence, Class, Licence expiry, Certified for, Employment, Joined, Active, Status (review state). Search by name, staff number or licence.

**Pagination.** 25 rows per page by default, with a selector for 25/50/100 and Previous/Next buttons; the page shows 'Showing 1–25 of N'.

**Add / Edit driver.** Opens a form with Basics, Licence, Certifications and Employment sections.

**Review status.** New or edited records may be marked 'Pending review' and wait in the Review Queue.


## Add a driver

1. Open **Driver Registry** and click **Add driver**.
2. Enter the **Full name** (required — 'Full name is required' appears if empty).
3. Add the phone number, licence number, class and expiry date.
4. Tick the machine types the driver is **Certified for** (Motor Grader, Front End Loader, Excavator, Dump Truck, Compactor, Other).
5. Choose the **Employment** type (Permanent, Contract, Seconded, Casual) and the date joined.
6. Save the record. The message 'Driver added to the registry' confirms.

## Find a driver

1. Type a name, staff number or licence number into the search box.
2. Use the page buttons to move through the list.
3. Click a row to open the driver's details for editing.

## Field reference

| Field | Description | Required | Rules / Format |
|---|---|---|---|
| Staff No | Automatic staff number, e.g. DRV-0001 | Automatic | Generated by the system; read-only |
| Full name | Driver's full name | Yes | Free text |
| Phone | Contact number | No | Free text |
| Licence number / Class / Expiry | Driving licence details | No | Free text and date |
| Certified for | Machine types the driver may operate | Yes for assignments | Multi-select of the six machine types |
| Employment | Employment arrangement | Yes | Permanent, Contract, Seconded, Casual |
| Joined | Date the driver joined | No | Date |

## Role notes

- A driver can only be assigned to a machine whose type is in their **Certified for** list — the system refuses mismatched assignments.
- Data Entry Staff and Data Entry Supervisors can add and edit drivers for their own hub; their entries may go to the Review Queue first.

> **Warning:** Check licence expiry dates regularly — expired licences are visible in the list so you can plan renewals.
