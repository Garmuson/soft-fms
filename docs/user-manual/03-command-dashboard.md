# Live Command Dashboard

## Overview

The command centre for the whole fleet. It shows the live map, headline figures, hub utilisation table and the open-alerts feed on one screen. This is the HQ Administrator's home screen.

## What you see

**Headline figures (KPI cards).** Total machines, machines active, hubs below the 80% utilisation target, open alerts, fuel on hand (galleries), and average utilisation — each card has a yellow strip along the top.

**Live map.** Every machine is a pin, coloured by status; hub depots are shown as zones. Click a pin to open a details panel with unit ID, type, status, operator, hub, project, fuel bar, last-seen time and GPS position.

**Hub table.** One row per hub: county, machine counts by status, utilisation percentage and open alerts. Click a hub row to open its full hub page.

**Alerts feed.** The most recent alerts, newest first, with level (critical, warning, info). Click **Acknowledge** on an alert you have acted on.


## Find a machine on the map

1. On **Live Overview**, click the machine's pin on the map.
2. Read the details panel: unit ID, machine type, status, operator, hub and project.
3. Check the fuel bar and the 'last seen' time to confirm the machine is reporting.
4. Close the panel when finished.

## Acknowledge an alert

1. Find the alert in the alerts feed (or open the **Alerts** page).
2. Click **Acknowledge**.
3. The message 'Alert acknowledged' appears and the alert stops counting as open. Your name and the time are saved in the Activity Log.

## Spot a hub below target

1. Look at the 'hubs below 80%' figure on the KPI cards.
2. In the hub table, sort or scan for the lowest utilisation.
3. Click the hub row to open its page and see which machines are idle or in maintenance.

## Role notes

- Only HQ Administrators can open this screen. Ministry Analysts use **National Overview** instead.

> **Tip:** The map and figures refresh by themselves — there is no need to reload the page.
