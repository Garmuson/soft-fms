# Shifts (Start & End)

## Overview

A shift records when a machine was operated, by whom, and the fuel gauge reading at the start and end. The difference is the tank used during the shift. Data Entry Staff run shifts for machines in their own hub.

## What you see

**My Machines / Shifts.** One card per machine in your hub with the unit ID, type, status badge, today's engine hours and a fuel gauge. Each card has **Start Shift**, **Log Fuel** and **Report Issue** buttons.

**Active shift.** While a shift is running, a pulsing 'Shift Active' badge appears on the machine card, with the start time and the starting fuel reading. The **End Shift** button replaces **Start Shift**.


## Start a shift

1. Open **Shifts** on your phone.
2. Find the machine you are about to operate.
3. Tap **Start Shift**.
4. Enter the **starting fuel level** (0–100%) when asked — 'Enter a fuel level between 0 and 100%' appears if the value is out of range.
5. The shift starts: the machine is set to Active, the badge starts pulsing, and the message 'Shift started · fuel N%' confirms.

## End a shift

1. On the machine card with the active shift, tap **End Shift**.
2. Enter the **ending fuel level** (0–100%).
3. The shift closes: the machine is set to Idle and the message shows how much of the tank was used, e.g. 'Shift ended · used 35% of tank'.

## Role notes

- Only one shift can run at a time for you — end the current shift before starting another.
- Your hub's machines are listed; other hubs' machines are not shown.

> **Tip:** If you lose signal mid-shift, keep working — entries are held on the device and sent when the connection returns (see the Offline Working chapter).
